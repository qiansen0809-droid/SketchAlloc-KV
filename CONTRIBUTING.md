# Contributing to LU-KV

Thank you for your interest in LU-KV! Here are the basic ways to get involved.

## Submitting an Issue

- For bugs, documentation errors, or feature suggestions, please open a GitHub Issue.
- Include a brief description of the problem, steps to reproduce, and your environment (Python version, model name, etc.).

## Contributing Documentation (Wiki)

- If you find anything inaccurate or missing in the docs, feel free to open an Issue or submit a PR to fix the relevant Markdown file.

## Contributing Code (Patch / PR)

1. Fork the repository and create a new branch from `main`.
2. Make your changes and verify that existing tests still pass (`make test`).
3. Sign off your commits (DCO):
   ```bash
   git commit -s -m "describe your change"
   ```
4. Open a Pull Request with a brief description of what you changed and how you tested it.

## Acceptance Criteria

- The change is clearly described and easy to review.
- It does not introduce obvious errors or break existing functionality.
- All contributions are welcome, big or small.

If you have any questions, feel free to open an Issue before diving in.
